# Tri des panneaux — Ben & Bois

Application de bureau de tri lumineux des panneaux (Mac + Windows).

Les versions se trouvent dans l'onglet **Releases** :
- **Mac** : `Tri des panneaux_x.y.z_universal.dmg` (Intel + Apple Silicon, signé et notarisé)
- **Windows** : `Tri des panneaux_x.y.z_x64-setup.exe`

L'application installée se met à jour automatiquement à partir de ce dépôt (`latest.json`).
